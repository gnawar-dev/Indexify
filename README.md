About
___
INDEXIFY is, at it's core, an organiser that preserves the original order of a downloaded playlist as intended by its Spotify playlist counterpart. This is particularly useful for iPod users that use Rockbox. 

On Rockbox, the default is to organise playlists in alphabetical order however by placing an index at the front of the song name to indicate its place in the playlist, it helps make playlists feel more familiar to navigate on the iPod.

Additionally, because of the local nature of iPods and the lack of internet connectivity, INDEXIFY intends to allow a method to "Synchronise" playlists. 
By plugging the iPod into the computer, INDEXIFY can search each playlist using Spotify's RESTful API connected to the user account to find the exact playlist's songs and compare the two to see if there are any discrepancies (I.e. missing or surplus songs that aren't there anymore).
What INDEXIFY can then do, is with user permission, to alter the iPod's content by deleting surplus music and adding a txt file with the name of the missing song(s), plus a Spotify link to the song. 

What INDEXIFY will NOT do is illegally download the song for you. It will only tell you the discrepancies. How the user obtains their music is up to them.
